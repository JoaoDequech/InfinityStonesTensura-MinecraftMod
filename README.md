# Infinity Stones · Tensura Edition

As seis Joias do Infinito para **Minecraft 1.21.1 / NeoForge**, feitas para rodar junto do **Tensura Reincarnated**.

- Cada joia tem a sua árvore de poderes, comprada com Aspectos da Existência.
- Todos os poderes ficam numa roda radial (tecla **H**): clique esquerdo usa, direito escolhe a segunda opção, meio abre o menu do poder e o scroll muda o nível.
- Manopla do Infinito com encaixe das joias e poderes próprios.
- As passivas começam desligadas: cada jogador liga o que quiser.
- Funciona em multiplayer e no survival, sem precisar de OP.

📖 **Wiki:** todos os poderes, controles e instalação em [Wiki](https://github.com/JoaoDequech/InfinityStonesTensura-MinecraftMod/wiki). Ela é atualizada automaticamente a cada mudança no código.

## Download
Baixe o `.jar` mais recente em **[Releases](https://github.com/JoaoDequech/InfinityStonesTensura-MinecraftMod/releases/latest)**.
Coloque o arquivo na pasta `mods` do cliente e do servidor.

## Requisitos
Minecraft 1.21.1, NeoForge 21.1.266+, Tensura Reincarnated 2.0.1.5, ManasCore 4.0.0.2 e Architectury 13.0.12.

## Compilar
```
gradlew build
```
O jar sai em `build/libs`. Precisa de JDK 21.
